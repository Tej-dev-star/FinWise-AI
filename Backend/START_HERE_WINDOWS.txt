FINWISE AI BACKEND - UPDATED VERSION
====================================

This ZIP fixes the circular import error by moving the shared SQLAlchemy
object into extensions.py. Do not copy only one Python file from this ZIP:
the files are designed to work together.

SETUP (Windows PowerShell)
--------------------------

1. Extract this ZIP to a NEW folder, for example:
   D:\Used_Materials\FinWise_AI_Backend_Updated

2. In VS Code, open that extracted folder (File > Open Folder).

3. Open a terminal in that folder and run these commands one at a time:

   python -m venv venv
   .\venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt

   If PowerShell blocks activation, run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   Then run the activation command again.

4. Copy .env.example to .env and replace the two development secrets with
   long random values.

5. Start the backend:

   python app.py

6. Test in a browser:
   http://127.0.0.1:5000/api/health

EXPECTED RESPONSE
-----------------
{"service": "FinWise AI API", "status": "ok"}

IMPORTANT
---------
- This ZIP contains the backend only; it does not include your frontend.
- Keep your old folder and database as a backup until this version runs.
- Do not delete a database containing data you need.
- Bank connection endpoints are a DEMO ONLY. They do not contact a real bank,
  read SMS, or retrieve actual bank transactions.
- Do not deploy this development server publicly.
